# ER diagram and data dictionary

Static documentation generated from `../backups/respaldo6.sql`.

- `index.html`: landing page and navigation.
- `erd/index.html`: interactive ER diagram with animation, relationships, and backup row counts.
- `diccionario/index.html`: static data dictionary for all tables and fields.
- `assets/css/main.css`: shared styles.
- `assets/js/esquema.js`: schema data used by the ER diagram.
- `assets/js/erd.js`: diagram rendering and interactions.

Open `index.html` locally. For GitHub Pages, publish the repository root and open `Practica03/diagrama/`, or configure an Actions workflow to publish this folder as the site artifact.
